# Integrations

## Accounting software

Tallybook syncs with QuickBooks Online and Xero. Connect them in **Settings → Integrations**. Invoices, payments and clients sync every 15 minutes in one direction, from Tallybook to your accounting software. Changes made in QuickBooks or Xero are not synced back.

## Payments

Online card payments are processed by Stripe. Connect your Stripe account in **Settings → Integrations → Stripe**. Stripe's own processing fees apply; Tallybook does not add any fee on top.

## Zapier and API

Tallybook has a Zapier app with triggers for new invoices, paid invoices and new clients. A REST API is available on the Business plan; you can create API keys in **Settings → Integrations → API**.
